# DATA 관통 PJT

## 프로젝트 개요
이 프로젝트는 JSON 파일을 읽고, 필요한 정보의 타입을 변경해가면서, 조건에 따라 데이터를 나누는 방식으로 진행한 파이썬 실습이다.
A1부터 A5까지 해보면서, 단순히 코드를 쓰는 것보다 데이터가 어떤 구조로 들어오고 어떻게 처리되는지 먼저 이해하는 게 더 중요하다는 걸 느꼈다.

## 1. JSON 파일 읽기
- `json.load()`를 사용해 JSON 파일을 파이썬에서 다룰 수 있게 만들었다.
- 외부 데이터 파일을 프로그램 안으로 불러오는 기본 흐름을 처음부터 익힐 수 있었다.

## 2. 파일 경로 설정
- `Path`를 이용해 파일 경로를 설정하는 방법을 배웠다.
- 현재 파일 기준으로 데이터를 찾을 수 있어서 코드가 훨씬 깔끔해진 느낌이었다.

## 3. A1: 책 제목 추출
- `data['item']` 안의 각 항목을 하나씩 보면서 제목만 뽑아냈다.
- 그 제목들을 리스트에 모으면서, 반복문이 어떻게 데이터를 처리하는지 조금씩 익혔다.

## 4. A2: 평균 가격 계산
- 도서의 판매 가격을 리스트로 모은 뒤, `sum()`과 `len()`을 사용해 평균값을 계산했다.
- 숫자 데이터를 다룰 때는 단순히 값을 꺼내는 것보다 계산까지 연결해 보는 게 중요하다는 걸 느꼈다.

## 5. A3: 평균 고객 리뷰 순위 계산
- `customerReviewRank` 값을 꺼내서 평균을 구했다.
- 숫자로 된 데이터를 보고 바로 의미를 해석하는 연습이 되었다.

## 6. A4: 제목과 작가를 딕셔너리로 저장
- 제목과 작가 정보를 한 쌍으로 묶어서 관리해보았다.
- 딕셔너리가 키와 값을 기준으로 정보를 정리하는 데 아주 편하다는 걸 느꼈다.

## 7. A5: 정가 범위별 분류
- 가격에 따라 도서를 나누는 조건문을 써봤다.
- 같은 범위에 속하는 제목들을 묶어서 출력하는 방식의 데이터 분류가 간편하게 느껴졌다.
- `setdefault()`를 사용해 딕셔너리 안에 리스트를 만들면서, 코드가 더 간결해지는 것도 알게 되었다.

## 8. 중요하게 배운 내용
- JSON 데이터의 구조를 먼저 이해하는 것
- 반복문으로 데이터를 하나씩 확인하는 것
- 리스트와 딕셔너리의 차이를 구분해서 사용하는 것
- 조건문으로 데이터를 나누는 것
- 결과를 보기 좋게 출력하는 것
- 오류가 나면 원인을 먼저 찾고 하나씩 수정해 보는 것

## 9. 어려웠던 부분
- python을 배운지 얼마 되지 않았는데 여러가지 명령어들과 타입을 사용해야 한다는게 어려웠다.
- 새로운 명령어를 Json 파일을 사용하는데에 적용하는데 적응시간이 걸렸다.
- 같이 프로젝트를 한 인원들도 대체적으로 수업 진도가 빠르다고 느끼고, 프로젝트에 배운것들을 전부 적용하는데에 어려움을 많이 느꼈다.

## 9. 느낀 점
이번 프로젝트를 하면서 Json 파일을 사용하는 법을 배우게 되어서 Json파일에 대한 어렵다는 고민이 해결될 수 있는 시간이었다.
처음엔 코드가 조금 어색했지만, 하나씩 실행해 보고 오류를 고치면서 점점 이해가 되는 느낌이었다.
특히 데이터를 어떻게 문자열에서 dict로 변환하는지, 그리고 값을 적용하는지 생각하는 과정이 생각보다 재미있었다.
